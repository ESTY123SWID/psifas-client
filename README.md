## על האתר

**פסיפס** הוא מקום משותף לזיכרונות של כיתה: משפטים שנאמרו בשיעור, תמונות מטיולים וטקסים, ותגובות של חברות הכיתה. כל כיתה היא מרחב פרטי שמצטרפים אליו בקוד.

### מה אפשר לעשות
- **אזור ציבורי** — דף בית לאתר, הרשמה והתחברות (`/register`, `/login`), ושחזור ההתחברות אחרי רענון.
- **כיתות** — יצירת כיתה וקבלת קוד הצטרפות, הצטרפות בקוד, בחירת כיתה פעילה ומעבר בין כיתות, עזיבת כיתה.
- **ניהול כיתה** (למנהלת הכיתה) — שינוי שם, קוד הצטרפות והחלפתו, שינוי תפקידים, הסרת חברות ומחיקת הכיתה. המנהלת האחרונה בכיתה מוגנת.
- **פרסומים** — משפטים ותמונות: יצירה, עריכה (כולל החלפת תמונה או הסרתה) ומחיקה; חיפוש, סינון לפי סוג ולפי "הפרסומים שלי", מיון ועימוד; עמוד לכל פרסום.
- **דף בית אישי** — "הזיכרון של היום", פרסומים ותמונות אחרונים, וחברות הכיתה.
- **גלריה** — כל התמונות של הכיתה הפעילה.
- **תגובות** — שמונה תגובות, אחת לכל משתמשת בכל פרסום.
- **פרופיל** — עריכת שם ואימייל, ושינוי סיסמה.
- **ממשק מנהלת מערכת** — סקירה כללית, ניהול משתמשות (חיפוש, סינון, תפקיד, מחיקה) וניהול כיתות (שם, חברות ותפקידים, מחיקה).
- עברית מלאה ו־**RTL**, מותאם למחשב ולטלפון, עם מצבי טעינה, שגיאה ורשימות ריקות בכל המסכים.

## התקנה והרצה

**דרישות:** Node.js 20.19 ומעלה, ו[שרת פסיפס](https://github.com/ESTY123SWID/psifas-server) שרץ מקומית.

```bash
npm install
npm run dev          # http://localhost:5173
```

| פקודה | תיאור |
|---|---|
| `npm run dev` | שרת פיתוח |
| `npm run build` | בדיקת TypeScript ובנייה לתיקיית `dist` |
| `npm run preview` | הצגת הבנייה מקומית |
| `npm run lint` | בדיקת קוד עם Oxlint |

## משתני סביבה

| משתנה | תיאור |
|---|---|
| `VITE_API_URL` | כתובת ה־API כולל `/api` |

- **בפיתוח** — מוגדר כבר ב־`.env.development`: `http://localhost:4000/api`.
- **בענן** — מגדירים את `VITE_API_URL` אצל ספק האחסון לפני הבנייה. תבנית: [`.env.example`](.env.example).

הקליינט אינו שומר סיסמאות או טוקנים: ההתחברות נשמרת ב־Cookie מסוג HttpOnly שהשרת מנהל, וכל בקשה נשלחת עם `credentials: "include"`.

## מבנה הקוד

```text
src/
├── app/          ← Redux store
├── assets/       ← הלוגו
├── components/   ← רכיבים לפי תחום: admin, classes, posts, members, layout, ui …
├── config/       ← הגדרות ניווט
├── features/     ← Redux slices (התחברות, כיתה פעילה)
├── pages/        ← מסכים: public, user, class, systemAdmin
├── routes/       ← נתיבים ו־Route Guards: RequireAuth, RequireClass, RequireSystemAdmin
├── services/     ← RTK Query: כל הקריאות לשרת
├── types/        ← טיפוסי TypeScript
└── tailwind.css  ← Design Tokens ורכיבי העיצוב הבסיסיים
```

## פרסום בענן (טרם בוצע)

אתר סטטי (Vercel, Netlify או Render Static Site): Build — `npm run build`, תיקיית פלט — `dist`, המשתנה `VITE_API_URL=https://<כתובת השרת>/api`, והפניית כל הנתיבים ל־`index.html`.
